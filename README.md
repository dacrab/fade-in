## ✨ What is FadeIn?

**FadeIn** connects customers with barbershops through a seamless booking experience. Customers can discover shops, book appointments, and leave reviews. Shop owners get a complete dashboard to manage their business, appointments, and team.

---

## 🎯 For Customers

- **Discover** barbershops near you with an interactive map
- **Book** appointments in just a few clicks
- **Choose** your preferred barber and services
- **Review** your experience and help others decide
- **Manage** all your bookings from one place
- **Save** your favorite shops for quick access

## 💼 For Business Owners

- **Manage** your shop profile and showcase your work
- **Track** appointments in real-time
- **Organize** your team of barbers
- **Set** services, prices, and availability
- **Respond** to customer reviews
- **Grow** your business with verified status

## 🚀 Getting Started

### For Developers

Want to run FadeIn locally? You'll need:
- [Bun](https://bun.sh) (version 1.3 or higher)
- A [Convex account](https://dashboard.convex.dev) (free to start)

**Quick start:**

```bash
# Install dependencies
bun install

# Set up your environment
cp .env.example .env.local
# Edit .env.local with your Convex credentials

# Start the backend (in one terminal)
bunx convex dev

# Start the app (in another terminal)
bun dev
```

Visit [http://localhost:3000](http://localhost:3000) and you're ready to go!

**Available commands:**

```bash
bun dev          # Start development server
bun run build    # Build for production
bun run preview  # Preview production build
bun run check    # Check code quality
```

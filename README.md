## What is FadeIn?

FadeIn connects customers with barbershops through a seamless booking experience. Find shops near you, book in a few clicks, and leave reviews — all from one place.

## For Customers

- Discover barbershops with an interactive map
- Book appointments in seconds
- Choose your barber and services
- Manage bookings and save favorites
- Leave reviews to help others

## For Business Owners

- Manage your shop profile and team
- Track appointments in real-time
- Set services, prices, and availability
- Respond to customer reviews
- Get verified and grow your business

## Features

- **Real-time availability** — no double-bookings
- **Interactive map** — find shops near you
- **Multi-step booking** — guided service → barber → date → time flow
- **Mobile-friendly** — works on any device
- **Multi-language** — English & Greek

## Getting Started

You'll need [Bun](https://bun.sh) 1.3+ and a [Convex account](https://dashboard.convex.dev).

```bash
bun install
# Set up secrets (via Doppler — or copy .env.example to .env)
doppler setup
bunx convex dev   # start backend
bun dev           # start app
```

Open [localhost:3000](http://localhost:3000).

## Scripts

```bash
bun dev          # development server
bun run build    # production build
bun run check    # lint & format
bun run test     # run tests
```
